### ⚔️ YOLOv5 vs YOLOv8: Custom Object Detection
<sub>B.Tech project (2023) · supervised by Dr. Mohd. Abdul Ahad, Dept. of CSE, Jamia Hamdard</sub>

A like-for-like comparison: same custom **12-class dataset**, same training recipe, compared on metrics and on the same test images.

- **Metrics:** near-identical mAP@0.5 (0.718 vs 0.721)
- **Detections:** YOLOv8 more confident on 12 of 25 shared detections and avoided one wrong-class error
- **Honest scope:** one run on a small dataset, a practical comparison, not a benchmark
